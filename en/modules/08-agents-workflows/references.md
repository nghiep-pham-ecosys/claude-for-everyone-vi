## Estimated cost

8 scripts, at most about 51 calls to the default model when run for real (01: 3; 02: 3; 03: 8; 04: 6; 05: 6; 06: 6; 07: 9; 08: 10). The number of calls in 03, 05, 07 and 08 depends on how many tools Claude calls, so this is the worst case set by the turn caps in the code. In mock mode the whole module makes 40 calls.

Worst-case output with Haiku 5.5 and `MAX_TOKENS=1024`: 51 × 1,024 × $0.50/MTok ≈ $0.026. Input: if each call reaches about 3,000 tokens (handbook pages, tool definitions, a growing history), 51 × 3,000 × $0.10/MTok ≈ $0.015. The whole module costs under $0.05. Prices are read from `config/models.yaml` (the "from" price of Haiku 5.5). This is an estimate, not yet measured with the real API.
