## Where the sources disagree

- The minimum Python version of `mcp` 2.x: the docs say 3.11+, the PyPI metadata says `>=3.10`. The repo uses Python 3.11 or later, so it is not affected.
- Calling a tool that does not exist: the spec treats it as a protocol error (JSON-RPC, for example `-32602`); the Python SDK 2.3.0 returns a `CallToolResult` with `is_error=True` (script 02 shows it). The lesson states both.
