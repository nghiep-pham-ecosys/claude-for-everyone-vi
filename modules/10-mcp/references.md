## Chỗ nguồn chưa khớp

- Phiên bản Python tối thiểu của `mcp` 2.x: docs ghi 3.11+, metadata trên PyPI ghi `>=3.10`. Repo dùng Python 3.11 trở lên nên không bị ảnh hưởng.
- Gọi tool không tồn tại: spec coi là lỗi giao thức (JSON-RPC, ví dụ `-32602`); SDK Python 2.3.0 trả `CallToolResult` với `is_error=True` (script 02 cho thấy). Bài viết nêu cả hai.
